用你自己的数据

  • id、label：节点的唯一编号和显示的名字。
  • parents：第一个是主干上的父节点，其余是融合进来的思路；根节点留空。
  • by 谁提出的，step 第几步长出来，status 填 growing 或 dormant，knot 表示团队确认过的树节，note 一句话说明。
  • 以后 skill 从对话记录里抽出来的就是这份 JSON，这棵树会直接把它画出来。
